# 人事管理ソフト

社員情報を中心に、入退社・有給休暇・退職者・労働者名簿を一元管理する日本語Webアプリです。

## 機能

- ダッシュボード
- 社員登録・編集・検索
- 有給休暇の付与・取得・調整、全社員の月別使用日数一括入力、前期間繰越・期間終了残数集計
- 有給管理期間は通常「前月16日～当月15日」、3月分は「2月16日～3月31日」、4月分は「4月1日～4月15日」
- 社員情報を残したまま、すべての有給データを一括削除
- 2027年以降、入社6か月後の初回付与と翌年4月1日以降の年次付与を自動登録
- 年度ごとの欠勤日数・出勤率を管理し、出勤率8割未満の場合は翌年度の4月付与を停止
- 入社・退社登録
- 退職者一覧・在籍への復元
- 労働者名簿の表示・印刷・PDF保存
- JSON形式のバックアップ・復元
- 従業員CSVインポート（CP932 / UTF-8）
- スマートフォン対応

## 使い方

`index.html` をブラウザで開くだけで利用できます。データはブラウザの `localStorage` に保存されます。同じ端末・同じブラウザで使用してください。

> 個人情報を扱うため、共有PCでの利用は避け、端末のログイン・暗号化・バックアップを適切に設定してください。
